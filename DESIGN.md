# DubStudio design direction

Operate mode. A quiet white editing desk with a crisp blue active state; real media is the visual focus.

Desktop topology: 56px header, 350px transcript panel, flexible player, 270px inspector, resizable bottom timeline. Thin neutral dividers, a pale gray player stage, subtle blue/green/purple track fills. Use system sans for legible Chinese, tabular numerals for times, Lucide icons, 6–10px control radii. No decorative cards, gradients or animation sequences. Status is explicit text plus icon.

Selection links transcript, preview and timeline. Transcript distinguishes narration from subtitles; generating a new take leaves old audio accessible. Empty state is an import surface, never fake project content. Dialogs reserve focus for settings/export. Keyboard shortcuts have visible hints. Narrow screens stack preview and transcript, inspector in a drawer, timeline horizontally scrolls.

User delegated design selection. Direction contract: deliver an immediately usable editor where sentence edits and time changes stay consistent, cloud task failures are recoverable, and real exports match the preview.

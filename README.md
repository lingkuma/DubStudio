# DubStudio

白色主题的逐句配音、AI 二创与浏览器视频编辑工作台。

## 本地运行

Node.js 22 或更新版本：

    npm install
    npm run dev

打开 http://127.0.0.1:5173 。进入右上角 API 设置，填写百炼、AutoDL 和 AI 中转凭证。开发服务器同时提供同站 API 代理，无需启动 Python、FFmpeg 或本地模型。

## Vercel 部署

把本项目推送到自己的 Git 仓库，在 Vercel 中导入，选择 Vite，构建命令 npm run build，输出目录 dist。保留 api/gateway.js 和 vercel.json。无需填写服务端环境变量，凭证由网页设置提供。

前端静态资源负责素材缓存、预览、剪辑、混音和视频导出；一个同站无状态函数处理 API 跨域。连接方式按阿里百炼、AutoDL、AI 三个渠道分别保存，互不影响；每个渠道都可选择浏览器直连、同站 / 自定义网关、自定义 Worker。AutoDL 请求默认直连，结果文件遇到跨域时可单独使用网关下载，也可关闭该回退。阿里与 AI 默认使用项目现有的 /api/gateway。

同站 / 自定义网关接收本项目 action JSON 协议；Worker 模式转发原始 API 请求，支持 https://proxy.example/?url={url}（编码目标 URL）、https://proxy.example/{rawUrl}（原始目标 URL），不写占位符时自动附加 url 查询参数。Worker 需转发请求方法、请求体、鉴权头并处理 CORS；阿里上传在 Worker 模式下也经过该 Worker，其他模式仍直传 OSS。各渠道的 Base URL 均可自定义，协议仍分别是百炼、AutoDL、OpenAI 兼容接口。

## 工作流程

1. 添加一个或多个 H.264/AAC MP4 视频；也可直接拖入中间的视频预览区域，已有视频时会追加到时间轴末尾。
2. 在设置中填写北京地域百炼 Key，点击识别字幕。音频在浏览器提取，直传百炼临时 OSS，不经过 Vercel 函数体积限制。
3. 默认按每句话在原视频中的起止时间提取原声，使用 AutoDL indextts2-v1 克隆。每句的「克隆参考音源」可单独改为自定义音色；单句生成和「生成待更新」都按这些配置执行。右侧音色库可上传 MP3/WAV 短音频（小于 2MB）、从选中句子提取参考、查看当前句使用标记和删除音色；新增参考不会自动改变句子配置，删除后相关句子恢复原句原声，也可撤销。旧工程已保存的音源选择会保留，需要时可点「全部恢复原句原声」。
4. 左侧编辑配音文本和字幕；两者可同步或独立修改。AI 助手读取全部台词、稳定句子 ID 和时间戳，提供全文或单句改写、智能匹配与可执行操作。
5. 拖动底部片段移动、裁切两端；S 在播放头分割。选择片段后可在属性里精确输入入点、出点和起点。导入多个视频即可顺序拼接，也可调整时间轴顺序。
6. 导出前选择字幕、画幅和帧率，浏览器本地输出 MP4。

## 字幕、试听与工作区

- 右侧「字幕」是独立属性页，支持字号（12–300 画布像素）、行间距（0–300 画布像素，默认 0，多行背景相连）、字体、加粗、文字颜色、8 种背景预设和自定义颜色、背景不透明度、描边颜色/宽度和顶部位置。位置固定字幕顶部，多行向下延伸；旧工程也使用此定位方式，缺省行间距为 0。遮盖原视频字幕时，可将黑色背景不透明度设为 100%。预览与导出使用相同渲染器，旧工程保留原来的黑色半透明底色。展开「当前句字幕」可设置文本同步、独立字幕和字幕偏移；左侧每句的「字幕」按钮可直接打开此页。
- 每句「原声」直接播放原视频中这句话的音轨，在原素材语音终点自动停止；「配音」播放生成结果。再次点击可停止，切换试听会停掉上一段，原声试听不受工程混音策略影响。
- 桌面拖动台词区/预览区、预览区/右侧工具的边界调整宽度，拖动时间轴上边界调整高度。方向键可微调，双击恢复默认，尺寸自动保存在当前浏览器。小屏继续使用工具抽屉及上下布局。

## 时间轴缩放

在时间轴内按 Ctrl + 滚轮，以鼠标下的时间点为中心缩放；滑块和加减按钮也可调节。相同滚动量对应相同的缩放变化，鼠标滚轮的大步输入通过 80ms 匀速过渡展开，每帧只提交一次几何更新。刻度、片段和播放头共用像素/时间映射，并保留滚动的亚像素精度。靠近工程边缘缩小时保留边界约束；拖动片段或操作滑块会立即结束尚未完成的缩放过渡。

## 配音任务池

单句「克隆」和「生成待更新」共用任务池，默认并发 10 条。生成按钮旁可设为 1–50 条，设置自动保存在当前浏览器。任意一条完成或失败，立即用下一条补位；不会等整批结束。运行中增大数量会立即补充，减小数量会等待已运行任务自然结束，再按新上限补充。

同一句在排队或生成时不会重复提交；其他句子仍可编辑、试听和加入队列。单条失败显示在该句上，其余任务继续。底部显示运行和排队数量；「停止」取消排队及本地等待，已提交云端任务可能继续，可用「继续查询」恢复。批量重试会复用配置仍匹配的任务。生成期间暂不可切换工程、撤销/重做、识别或导出，完成后恢复；中途编辑过的台词会在旧文本音频返回后标记待更新。

## 导入与保存

- TXT 按非空行对应现有句子，行数不匹配会拦截，不默默丢句。
- SRT 使用时间戳建立分段；跨越视频剪辑边界的字幕需要先调整。
- AI 智能导入给出匹配建议，保留稳定 ID；应用前可逐句检查。
- 自动保存使用 IndexedDB；「保存」下载包含所有原素材和生成音频的 .dubstudio 工程包，可以在其他设备重新打开。工程包不含 API Key，包含台词与对话历史。
- API 设置修改后立即自动保存到当前浏览器的 localStorage，包含所有渠道的 API Key；刷新或重新打开仍可使用。

## 配置分享链接

在 API 设置中点击「复制配置分享链接」，即可将当前全部设置（含各渠道 Base URL、Key、连接方式、网关 / Worker 地址、结果下载回退、热词、说话人识别和 AI 模型）分享给朋友。链接使用 `?config=` 加 URL 编码的 JSON。对方打开后自动导入并保存，用 `history.replaceState` 清除配置参数，不刷新页面，也不留下额外的带配置历史条目；收藏当前页面即可得到干净地址。链接包含 Key，请发给你希望使用这些 Key 的朋友。

也可直接拼接参数，仅覆盖提供的字段，其余保留本机已有值。字段值须用 `URLSearchParams` 或 `encodeURIComponent` 编码，尤其是 Key 中的 `+`、`&` 和嵌套代理 URL：

```js
const params = new URLSearchParams({
  aliyunKey: "百炼 Key",
  asrBase: "https://dashscope.aliyuncs.com",
  "asr.transport": "gateway",
  "asr.gateway": "/api/gateway",
  autodlKey: "AutoDL Token",
  autodlBase: "https://autodl.art",
  "tts.transport": "direct",
  "tts.downloadFallback": "true",
  "tts.gateway": "/api/gateway",
  aiKey: "AI Key",
  aiBase: "https://api.example.com/v1",
  aiModel: "your-model",
  "ai.transport": "worker",
  "ai.workerUrl": "https://proxy.example/?url={url}",
  hotwords: "品牌,人名",
  diarization: "false",
});
const shareUrl = "https://你的站点/?" + params.toString();
```

三个渠道前缀分别是 `asr`、`tts`、`ai`；每个渠道均支持 `.transport`（`direct` / `gateway` / `worker`）、`.gateway`、`.workerUrl`、`.downloadFallback`。布尔参数支持 `true` / `false` / `1` / `0`。也支持单独使用任意文本字段：`aliyunKey`、`autodlKey`、`asrBase`、`autodlBase`、`aiBase`、`aiKey`、`aiModel`、`hotwords`。同时提供 `config` 和单独参数时，单独参数优先。无效配置整次不导入；浏览器禁止本地存储时会提示保存失败并保留原链接供重试。无关查询参数与页面锚点会保留。

## 技术范围

优先支持现代桌面 Chrome / Edge，导出需要 WebCodecs 和 H.264/AAC 编码能力。首版聚焦基础多轨剪辑、逐句配音和字幕，不包含复杂转场、云端口型同步、人声分离或专业调色。替换原声的区间也会移除原视频中混在同一音轨的环境声，可另加背景音乐。

长于原句的配音使用 SoundTouchJS 保持音高的时间伸缩；压缩幅度大时建议改短台词。AI 控制字数不等于保证实际语音时长。现有画面中已烧录的字幕不会被自动擦除。

API 代理接受自定义公网 HTTPS 服务与结果文件域名，不再限定 0-0.pro / OpenAI 或厂商域名。保留 URL 格式、URL 内嵌账号密码、显式本机 / 内网 IP 以及重定向检查；这些基本检查不是身份验证，也不保证完整的 SSRF 防护。函数不内置、不保存用户 Key，也不转发用户登录 Cookie。

当前代理没有调用者身份验证：知道公开 /api/gateway 地址的人可以直接发送请求，消耗该部署的调用额度和流量，包括不带 API Key 的结果下载。因为服务端没有共享模型 Key，这不代表可直接使用站主的模型余额。同一账户下其他 Worker 不会自动经过本接口，但主动请求该地址仍可使用它。供个人/团队使用时，可在部署平台启用站点访问保护，并确保 API 路径也受到保护；仅限制 CORS 或 Origin 不能代替身份验证。

# DubStudio

白色主题的逐句配音、AI 二创与浏览器视频编辑工作台。

## 本地运行

Node.js 22 或更新版本：

    npm install
    npm run dev

打开 http://127.0.0.1:5173 。进入右上角 API 设置，填写百炼、AutoDL 和 AI 中转凭证。开发服务器同时提供同站 API 代理，无需启动 Python、FFmpeg 或本地模型。

## Vercel 部署

把本项目推送到自己的 Git 仓库，在 Vercel 中导入，选择 Vite，构建命令 npm run build，输出目录 dist。保留 api/gateway.js 和 vercel.json。无需填写服务端环境变量，凭证由网页设置提供。

前端静态资源负责素材缓存、预览、剪辑、混音和视频导出；一个同站无状态函数处理 API 跨域。若部署到纯静态空间，可在设置切换「浏览器直连」，但 API、上传和结果下载均必须支持 CORS，或填写自己的兼容代理地址。

## 工作流程

1. 添加一个或多个 H.264/AAC MP4 视频。
2. 在设置中填写北京地域百炼 Key，点击识别字幕。音频在浏览器提取，直传百炼临时 OSS，不经过 Vercel 函数体积限制。
3. 在音色面板上传 MP3/WAV 短音频（小于 2MB），使用 AutoDL indextts2-v1 逐句克隆。
4. 左侧编辑配音文本和字幕；两者可同步或独立修改。AI 助手读取全部台词、稳定句子 ID 和时间戳，提供全文或单句改写、智能匹配与可执行操作。
5. 拖动底部片段移动、裁切两端；S 在播放头分割。选择片段后可在属性里精确输入入点、出点和起点。导入多个视频即可顺序拼接，也可调整时间轴顺序。
6. 导出前选择字幕、画幅和帧率，浏览器本地输出 MP4。

## 导入与保存

- TXT 按非空行对应现有句子，行数不匹配会拦截，不默默丢句。
- SRT 使用时间戳建立分段；跨越视频剪辑边界的字幕需要先调整。
- AI 智能导入给出匹配建议，保留稳定 ID；应用前可逐句检查。
- 自动保存使用 IndexedDB；「保存」下载包含所有原素材和生成音频的 .dubstudio 工程包，可以在其他设备重新打开。工程包不含 API Key，包含台词与对话历史。
- API Key 默认保存在会话存储，勾选记住后才保存于 localStorage。

## 技术范围

优先支持现代桌面 Chrome / Edge，导出需要 WebCodecs 和 H.264/AAC 编码能力。首版聚焦基础多轨剪辑、逐句配音和字幕，不包含复杂转场、云端口型同步、人声分离或专业调色。替换原声的区间也会移除原视频中混在同一音轨的环境声，可另加背景音乐。

长于原句的配音使用 SoundTouchJS 保持音高的时间伸缩；压缩幅度大时建议改短台词。AI 控制字数不等于保证实际语音时长。现有画面中已烧录的字幕不会被自动擦除。

API 代理只允许已知服务域名，不内置凭证；自定义 AI 服务可用直连或自托管代理。函数请求不保存用户 Key，也不转发用户登录 Cookie。公开部署建议使用 Vercel 的站点访问保护供个人/团队使用。
